# Implementation references

The setup workflow relies on the following upstream documentation:

- Visual Studio Code installation on Linux: <https://code.visualstudio.com/docs/setup/linux>
- Microsoft Linux software repositories and signing keys: <https://learn.microsoft.com/en-us/linux/packages>
- Kali Linux hostname configuration: <https://www.kali.org/docs/general-use/changing-hostname/>
- Kali Linux package updates: <https://www.kali.org/docs/general-use/updating-kali/>
- OpenSSH `ssh-keygen`: <https://man.openbsd.org/ssh-keygen>
- Linux `usermod`: <https://man7.org/linux/man-pages/man8/usermod.8.html>
- systemd journal configuration: <https://www.freedesktop.org/software/systemd/man/latest/journald.conf.html>
- Ubuntu UFW manual: <https://manpages.ubuntu.com/manpages/noble/en/man8/ufw.8.html>
- Xfce Power Manager preferences: <https://docs.xfce.org/xfce/xfce4-power-manager/preferences>
